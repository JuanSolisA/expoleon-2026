# ExpoLeón 2026 · Recorrido del taller

Plano interactivo del sector taller del Colegio León XIII para la ExpoLeón 2026: qué curso expone en cada espacio, cómo llegar entre las tres plantas y vistas 360°.

Sitio: https://juansolisa.github.io/expoleon-2026/

Cada espacio tiene su propio enlace para los códigos QR, por ejemplo `#hall` marca "Estás acá" en el hall del taller.
